# YOLO 环境安装工具使用说明

## 软件位置

打包后的程序位于：

```text
dist\YoloInstaller.exe
```

双击 `YoloInstaller.exe` 即可打开。程序本身不需要单独安装到系统中。

## 使用前准备

1. 建议电脑已经安装 Anaconda 或 Miniconda。
2. 如果电脑没有 Conda，可以在检测页点击“一键安装 Miniconda”。
3. 安装 PyTorch、Ultralytics 等包时需要联网。
4. Conda 安装目录建议使用英文路径，避免中文、空格和特殊符号。

## 基本使用流程

1. 打开 `YoloInstaller.exe`。
2. 在检测页确认系统、Conda、显卡、CUDA 和磁盘信息。
3. 如果未检测到 Conda，点击“一键安装 Miniconda”，选择安装目录并等待完成。
4. 进入安装配置页。
5. 填写环境名称，例如 `yolo-env`。
6. 选择 Python 版本，可选 `3.10`、`3.11`、`3.12`，也可以手动输入其他版本。
7. 确认 Conda 安装目录。
8. 按需选择是否安装 PyTorch、Ultralytics、Jupyter。
9. 点击“开始安装”。
10. 等待进度条完成，并在日志区域查看安装过程。

## Conda 安装目录说明

Conda 安装目录是当前 Anaconda 或 Miniconda 的根目录，不是软件本体目录，也不是 YOLO 工作目录。

例如检测到：

```text
D:\Apps\Anaconda3\Scripts\conda.exe
```

软件会自动填写：

```text
D:\Apps\Anaconda3
```

创建的 YOLO 环境通常会位于：

```text
D:\Apps\Anaconda3\envs\yolo-env
```

## 一键安装 Miniconda

如果检测页显示未找到 Conda，可以点击“一键安装 Miniconda”。

建议选择非 C 盘英文路径，例如：

```text
D:\Miniconda3
E:\Apps\Miniconda3
```

安装完成后，软件会自动重新检测 Conda，并把新的 Conda 安装目录填入配置页。

## Python 版本选择

默认推荐使用 `3.10`，兼容性通常最好。

也可以选择：

- `3.11`：较新，通常可用。
- `3.12`：更新版本，如果某些包安装失败，可以改回 `3.10`。
- 手动输入：适合明确知道 Conda 和依赖包支持该版本时使用。

## 安装过程中取消

安装页支持取消长时间运行的任务。点击取消后，程序会尝试停止当前安装步骤。

如果取消后环境残留，可以重新打开软件继续安装，或使用卸载功能清理环境。

## 常见问题

### 为什么不建议安装到 C 盘？

这是提醒，不一定会阻止安装。建议换到 D 盘或 E 盘，减少权限和空间问题。

### 为什么中文路径不建议使用？

部分 Python 包、命令行工具或第三方库对中文路径兼容不好。为了减少安装失败，建议使用英文路径。

### 为什么显示 Windows 10？

部分底层接口或打包运行时可能返回 Windows 10 内核兼容标识。软件会尽量识别 Windows 11，这类显示差异通常不影响安装。

### 安装失败怎么办？

1. 先查看日志区域最后几行错误。
2. 确认 Conda 能正常使用。
3. 确认 Conda 安装目录是正确的 Anaconda 或 Miniconda 根目录。
4. Python 版本优先选择 `3.10`。
5. 网络不稳定时，重新点击安装再试。

## 校验文件

打包时会生成：

```text
dist\YoloInstaller.exe.sha256
```

它用于校验 `YoloInstaller.exe` 文件是否完整。普通使用时可以不用处理。
