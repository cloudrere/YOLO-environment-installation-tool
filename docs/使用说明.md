# YOLO 环境安装工具使用说明

## 软件位置

打包后的程序在：

```text
E:\CodexProject\Yoloenv\dist\YoloInstaller.exe
```

双击 `YoloInstaller.exe` 即可打开。程序不需要单独安装到系统里，它本身就是一个可执行文件。

## 使用前准备

1. 电脑需要已经安装 Anaconda 或 Miniconda。
2. 建议保持网络可用，安装 PyTorch、Ultralytics 等包时需要联网下载。
3. 建议把安装目录放在 D 盘、E 盘等非系统盘。
4. 安装目录路径建议只使用英文、数字、下划线，避免中文路径和特殊符号。

## 基本使用流程

1. 打开 `YoloInstaller.exe`。
2. 在检测页确认系统、Conda、显卡、磁盘信息。
3. 点击下一步进入安装配置页。
4. 填写环境名称，例如 `yolo-env`。
5. 选择 Python 版本，可选 `3.10`、`3.11`、`3.12`，也可以手动输入其他版本。
6. 选择安装目录，推荐类似：

```text
D:\YoloWorkspace
E:\YoloWorkspace
```

7. 按需勾选 `安装 Jupyter` 和 `创建桌面快捷方式`。
8. 点击 `开始安装`。
9. 等待安装完成，安装过程中可以在日志区域查看进度。

## 安装目录说明

安装目录不是软件本体的位置，而是 YOLO 环境相关文件和工作目录的位置。

推荐：

```text
D:\YoloWorkspace
E:\YoloWorkspace
```

不推荐：

```text
C:\Users\用户名\Desktop\YOLO环境
C:\Program Files\YoloWorkspace
```

原因是 C 盘容易受权限、空间、中文用户名路径影响，可能导致后续包安装或模型运行失败。

## Python 版本选择

默认推荐使用 `3.10`，兼容性通常最好。

也可以选择：

- `3.11`：较新，通常可用。
- `3.12`：新版本，如果某些包安装失败，可以改回 `3.10`。
- 手动输入：适合你明确知道 Conda 和依赖包支持该版本时使用。

## 安装过程中取消

安装页支持取消长时间运行的命令。点击取消后，程序会尝试停止当前安装步骤。

如果取消后环境残留，可以重新打开软件继续安装，或使用卸载功能清理环境。

## 常见问题

### 为什么提示不建议安装到 C 盘？

这是提醒，不一定会阻止安装。建议换到 D 盘或 E 盘，减少权限和空间问题。

### 为什么中文路径不能用？

部分 Python 包、命令行工具或第三方库对中文路径兼容不好。为了减少安装失败，软件会阻止明显不安全的中文路径。

### 为什么显示 Windows 11？

软件会根据系统版本号识别 Windows 11。部分打包日志可能显示 Windows-10 内核标识，这是 Windows 兼容层和 PyInstaller 的平台显示方式，不影响软件识别。

### 安装失败怎么办？

1. 先看日志区域最后几行错误。
2. 确认 Conda 能正常使用。
3. 换成非 C 盘英文路径。
4. Python 版本优先选 `3.10`。
5. 网络不稳定时，重新点击安装再试。

## 校验文件

同目录下会生成：

```text
E:\CodexProject\Yoloenv\dist\YoloInstaller.exe.sha256
```

它用于校验 `YoloInstaller.exe` 文件是否完整。普通使用时可以不用管。
